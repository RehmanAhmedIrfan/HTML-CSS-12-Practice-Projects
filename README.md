# HTML-CSS 12 Practice Projects

Welcome to the **HTML-CSS 12 Practice Projects** repository! 🚀  
This repository contains 12 beginner-to-intermediate level web development projects built using **HTML5** and **CSS3**. These projects are aimed at strengthening foundational front-end development skills and enhancing design capabilities.

🌐 **Live Portfolio:**  
All projects are deployed and accessible from my portfolio site:  
👉 [View Projects Live](https://12-html-css-projects-by-rehman-ahmed.netlify.app/)

---

## 📁 Projects List

| No. | Project Name                                | Description |
|-----|---------------------------------------------|-------------|
| 01  | 2Pac Tribute Website                         | Tribute site dedicated to 2Pac, showcasing images and biography. |
| 02  | Job Application Form                         | A simple, responsive job application form. |
| 03  | Parallax Website                             | Parallax scrolling effect with visually appealing layout. |
| 04  | Developer Landing Page                       | Landing page for showcasing a developer profile. |
| 05  | Restaurant Website                           | A basic restaurant website with menu and contact info. |
| 06  | Music Website                                | Music-themed website with artist info and links. |
| 07  | Blog Website                                 | Basic blog layout with content sections. |
| 08  | Responsive Navigation Bar                    | Responsive navbar using pure CSS. |
| 09  | Side Navigation Bar                          | A vertical sidebar navigation bar. |
| 10  | Login Registration Form                      | A clean login and registration form design. |
| 11  | Responsive Contact Us Form                   | A modern, responsive contact form. |
| 12  | Responsive Footer                            | A stylish and responsive footer layout. |
| -   | Final Project - Portfolio Website            | A complete portfolio website integrating multiple elements from above projects. |

## 🛠️ Tech Stack
